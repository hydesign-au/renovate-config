# Renovate configuration

Shared Renovate policy for hydesign-au repositories.

```json5
{
  extends: ["local>hydesign-au/renovate-config"],
}
```

Repository-specific rules belong in each repository's `.renovaterc.json5`.

Based on [home-operations/renovate-config](https://github.com/home-operations/renovate-config/tree/3563e8fcfd50d24d444d84bd3047a65e115f2ffd).
